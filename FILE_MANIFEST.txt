=================================================================
  QUICK COMMAND REFERENCE
=================================================================

Run the demo:
  sudo ./demo.sh

Run individual modules:
  sudo ./hids.sh --module 1        (System health)
  sudo ./hids.sh --module 2        (User activity)
  sudo ./hids.sh --module 3        (Process & network)
  sudo ./hids.sh --module 4        (File integrity)

Create/reset baseline:
  sudo ./hids.sh --baseline

Run with demo config (less noisy):
  sudo ./hids.sh --config hids.demo.conf

View alerts:
  cat /var/log/hids/alerts.log     (human format)
  jq . /var/log/hids/alerts.jsonl  (machine format)

Install for automatic execution:
  sudo ./install.sh

=================================================================
  KEY DECISION POINTS
=================================================================

1. Module 1 uses ABSOLUTE thresholds (CPU load > 2.0 is bad)
   because system health is naturally dynamic.

2. Module 4 uses BASELINE comparison (file hashes)
   because file integrity should never unexpectedly change.

3. All thresholds go in hids.conf, never hardcoded in modules.

4. Whitelists (PORT_WHITELIST, PROCESS_WHITELIST) reduce noise.

5. ALERT_COOLDOWN prevents alert spam (default 1 hour).

6. Structured JSON output allows parsing by SIEM tools.

=================================================================
  ALERT CODES
=================================================================

Module 1 (System Health):
  SYS-001  High CPU load per core
  SYS-002  High memory usage
  SYS-003  High swap usage
  SYS-004  High disk usage

Module 2 (User Activity):
  USR-001  Failed login spike
  USR-002  Suspicious account (low UID, interactive)

Module 3 (Process & Network):
  PRC-001  Process from /tmp, /dev/shm, /var/tmp
  PRC-002  Process running from deleted binary
  PRC-003  Process exceeds CPU/memory threshold
  NET-001  Unexpected listening port
  NET-002  Suspicious shell with outbound connection

Module 4 (File Integrity):
  FIM-001  File permission violation
  FIM-002  New SUID binary detected
  FIM-003  Critical file content changed (hash mismatch)
